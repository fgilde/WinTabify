Installation

Set up WinTabify.

  1. Choose a Windows download

    Use x64 on Intel or AMD and Arm64 on Snapdragon. The slim version uses the .NET 10 Desktop Runtime for your architecture. Setup offers to install it if needed.

    Single-EXE installers
    Windows Runtime included Slim download
    x64 EXE ↓ EXE ↓
    Arm64 EXE ↓ EXE ↓
    Portable ZIP downloads

    Extract the entire ZIP into a writable folder and start WinTabify. Keep the updater files alongside the app.

    • x64 · Runtime included · Slim ZIP
    • Arm64 · Runtime included · Slim ZIP

  2. Run setup

    Open the downloaded EXE. WinTabify installs for your account and appears in the notification area. Coming from the original ZIP? Quit that copy first. Your shortcut and tab preference carry over.

  3. Try the shortcut

    The first launch shows your shortcut. Open two Explorer windows at different folders, close settings and press the combination. You can also choose Gather Explorer windows in the tray menu.

Requires Windows 11 with Explorer tabs (22H2 with the tab update or later).

Guide

Working with tabs.

What happens to existing tab groups?

Say you have one window with three tabs and then open two more folders in separate windows. The tray setting determines the result.

Include groups After gathering
On (default) One window with a tab for each distinct folder from all three windows.
Off The original three-tab window stays open. The two single windows form their own group.
How do I change the shortcut?

Double-click the tray icon, click the current shortcut, press the new keys together and save. At first launch WinTabify tries Ctrl + Win + E, then Alt + Win + E, then Ctrl + Shift + F11. If Windows declines a combination, choose another one in settings. The tray command is always available once you close settings.

Which window stays open?

WinTabify keeps the eligible window with the most distinct tabs and opens only missing folders. It closes other eligible windows once their locations are confirmed, including windows that contain only duplicates. If every eligible window already contains duplicate tabs, it creates a clean destination. An unreadable or changed window can stay open.

How do updates work?

WinTabify checks at startup and every six hours. It downloads updates for your architecture and runtime choice in the background, then restarts when folder gathering is finished and settings are closed. You can turn automatic updates off in Settings or choose Check for updates in the tray menu.

Start at sign-in or uninstall

For auto-start, copy the installed Start menu shortcut to shell:startup. To uninstall, quit from the tray and choose WinTabify in Windows Settings → Apps. For a portable copy, remove its extracted folder. Preferences are stored in %LOCALAPPDATA%\WinTabify.
